Welcome, HYVR author

This page is your starting point — folder structure, the block Library, drafts, and how preview/publish works. Bookmark it.

Folder structure

Site pages
/
Home, About, Products, Community, Support, Privacy, Contact — the real, live site pages.
/product/*
One page per product detail page (PDP).
Author tools
/block-library/*
One labelled, insertable example per block. Open one, copy its table, paste into your page, then edit the content.
/drafts/*
Scratch space — excluded from search, the product index, and the sitemap. Draft freely, preview normally, move the page out when it's ready to go live.

Working with blocks

1. Find the block

Browse /block-library for every available block with a working example.

2. Copy the table

Each block is authored as a table — the block name in the first row, then one row per field. Copy it as-is.

3. Edit the content

Change the text/links/images inside the table cells. Don't rename the block's first-row heading.

Plain headings and paragraphs need no table at all — just write them like a normal document.

Drafting a new page

Duplicate /drafts/starter-page as your base — it has a hero, a plain-content section, a cards block, and a call-to-action already wired up, with inline notes on what to replace.

Preview & publish

Preview
Open the page in DA → Sidekick → Preview. Renders at <branch>--hyvr-eds--clporgs.aem.page.
Publish
Sidekick → Publish once you're happy. Goes live at <branch>--hyvr-eds--clporgs.aem.live.
Images
Use DA's asset picker where available; otherwise reference an existing icon under /icons. Ask the platform team before adding new binary assets.

Questions?

Ask in the team channel, or open /drafts to try things out first — nothing there can break the live site.
